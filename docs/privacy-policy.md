# Политика конфиденциальности — insta-manager

_Последнее обновление: 8 августа 2026_

## Что это за приложение

**insta-manager** — персональный инструмент, который его владелец запускает
локально на собственном компьютере. Приложение читает через официальный
Instagram API посты, комментарии и статистику **только того Instagram-аккаунта,
который принадлежит владельцу приложения**, и сохраняет их на его же компьютере.

Приложение не размещено в интернете, не имеет пользователей помимо владельца и
не предоставляет доступ третьим лицам.

## Какие данные обрабатываются

Через Instagram API приложение получает:

- публикации аккаунта владельца и их метаданные;
- комментарии к этим публикациям, включая имена пользователей и тексты;
- статистику публикаций (охват, просмотры, вовлечённость);
- расшифровку речи из собственных видео владельца.

## Где хранятся данные

Все полученные данные сохраняются в виде файлов JSON в локальной папке `data/`
на компьютере владельца. Ни база данных в интернете, ни облачное хранилище, ни
сервер не используются.

## Кому данные передаются

Данные не продаются, не публикуются и не передаются третьим лицам.

Единственная внешняя передача — расшифровка видео: аудиодорожка публикации
владельца отправляется в OpenAI API для распознавания речи и возвращается
текстом. На неё распространяется
[политика конфиденциальности OpenAI](https://openai.com/policies/privacy-policy/).
Комментарии, имена пользователей и статистика в OpenAI не отправляются.

## Срок хранения и удаление

Данные хранятся, пока владелец их не удалит. Удаление — это удаление папки
`data/` на компьютере владельца; никаких других копий не существует.

Маркер доступа Instagram хранится в той же локальной папке и отзывается
удалением приложения в
[настройках Instagram](https://www.instagram.com/accounts/manage_access/).

## Права пользователей, оставивших комментарии

удалён из локальной копии, напишите на адрес ниже — копия будет удалена.
Обратите внимание, что сам комментарий в Instagram при этом не затрагивается:
управлять им можно средствами Instagram.
