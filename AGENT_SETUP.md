# Инструкция для ИИ-агента: настройка insta-manager

Этот файл написан для ИИ-агента (Claude, ChatGPT и т. п.), который помогает человеку настроить insta-manager. Человек может не разбираться в программировании. Веди его по шагам, по одному шагу за раз, дожидайся подтверждения, что шаг сделан, и только потом давай следующий. Говори простым языком, на языке пользователя.

## Правила для агента
- Никогда не проси пользователя прислать тебе маркер доступа, ключ OpenAI или секрет приложения. Пользователь вставляет их сам: маркер на странице http://localhost:3000/settings, ключ OpenAI в файл `.env.local`.
- Если интерфейс Meta на другом языке или выглядит иначе, попроси скриншот и сориентируйся по нему.
- Если что-то не получается, сначала спроси точный текст ошибки.

## Шаг 0. Проверить, что есть
Спроси пользователя:
1. Какая у него система: Mac или Windows.
2. Аккаунт Instagram профессиональный (Автор или Бизнес)? Если нет: Instagram → Настройки → Тип аккаунта и инструменты → Переключиться на профессиональный аккаунт.
3. Есть ли у него ключ OpenAI (нужен только для расшифровки видео; без него работают посты, комментарии и статистика). Ключ создаётся на platform.openai.com → API keys, баланс пополняется отдельно.

## Шаг 1. Установить Node.js
- Проверка: в Терминале (Mac) или PowerShell (Windows) команда `node -v` должна показать v20 или новее.
- Если нет: скачать LTS с https://nodejs.org и установить.
- Для расшифровки длинных видео нужен ffmpeg: на Mac `brew install ffmpeg` (если нет Homebrew, можно пропустить, короткие видео работают и без него).

## Шаг 2. Скачать проект
- Вариант без git: на странице репозитория GitHub зелёная кнопка Code → Download ZIP, распаковать в удобную папку.
- Вариант с git: `git clone <ссылка на репозиторий>`.

## Шаг 3. Ключ OpenAI (нужен для транскриптов)
Без ключа работают посты, статистика, комментарии и выгрузка. С ключом появляются транскрипты видео, темы комментариев (/topics) и расшифровка черновиков (/drafts). Для анализа «7 грехов» транскрипты очень желательны. Спроси пользователя, хочет ли он их, и если да, проведи по шагам:
1. Открыть https://platform.openai.com и войти (можно тем же аккаунтом, что и ChatGPT). Объясни: подписка ChatGPT Plus сюда не подходит, API оплачивается отдельно.
2. Пополнить баланс: Settings → Billing → Add payment details / Add to credit balance. Минимального пополнения (обычно 5 долларов) хватит надолго: расшифровка стоит доли цента за минуту видео. Точную цену пусть посмотрит на странице Pricing.
3. Создать ключ: Dashboard → API keys → Create new secret key → любое название (например, insta-manager) → скопировать. Предупреди: ключ показывается один раз, его нельзя никому отправлять, в том числе тебе.
4. В папке проекта скопировать `.env.example` в `.env.local` (Mac: `cp .env.example .env.local`; Windows: `copy .env.example .env.local`). Если файл не виден в Finder, нажать Cmd+Shift+. чтобы показать скрытые файлы.
5. Открыть `.env.local` в любом текстовом редакторе, вставить ключ сразу после `OPENAI_API_KEY=` без пробелов и кавычек, сохранить.
6. Если сервер уже запущен, перезапустить его (закрыть окно Терминала и снова запустить), чтобы ключ подхватился.
7. Проверка: на http://localhost:3000/settings у OPENAI_API_KEY должно стоять «задан».
Частые ошибки: `insufficient_quota` или 429 значит, что не пополнен баланс; `invalid_api_key` значит, что ключ вставлен с пробелом или не полностью.

## Шаг 4. Создать приложение Meta
1. Открыть https://developers.facebook.com, войти через Facebook, при первом входе зарегистрироваться как разработчик.
2. «Мои приложения» → «Создать приложение».
3. Сценарий использования: «Управление сообщениями и контентом в Instagram» (Instagram API). Бизнес-портфолио не нужно, если спросит, можно пропустить.
4. В приложении слева: «Сценарии использования» → Instagram API → «Настроить».
5. «Разрешения и функции»: добавить `instagram_business_basic`, `instagram_business_manage_comments` и обязательно `instagram_business_manage_insights` (без него не будет статистики).
6. Открыть пункт «Настройка API для входа в Instagram для бизнеса». НЕ «API setup with Unified login»: тот вариант требует бизнес-портфолио.
7. «Роли приложения» → «Роли» → добавить свой Instagram-аккаунт как тестировщика Instagram. Потом в самом Instagram: Настройки → Приложения и сайты → Приглашения тестировщиков → принять.

## Шаг 5. Перевести приложение в режим Live (нужно для комментариев)
В режиме разработки Instagram не отдаёт тексты чужих комментариев. Live не делает приложение публичным: пользоваться им сможет только владелец.
1. Опубликовать политику конфиденциальности: взять текст из `docs/privacy-policy.md`, заменить `<ВАШ_EMAIL>` на свой email, создать публичный Gist на https://gist.github.com и скопировать ссылку.
2. В приложении Meta: «Настройки приложения» → «Основное» → «URL политики конфиденциальности» → вставить ссылку → сохранить.
3. Переключатель режима вверху страницы → Live.

## Шаг 6. Запустить проект
- Mac: двойной клик по `Запустить.command` в папке проекта. Если macOS блокирует: правый клик → Open → Open. Скрипт сам установит зависимости и откроет браузер.
- Windows или вручную: в папке проекта выполнить `npm install`, потом `npm run dev`.
- Откроется http://localhost:3000. Окно терминала не закрывать, пока пользуешься приложением.

## Шаг 7. Сгенерировать маркер и подключить аккаунт
1. В приложении Meta: «Настройка API для входа в Instagram для бизнеса» → шаг 2 «Сгенерируйте маркеры доступа» → у своего аккаунта «Сгенерировать маркер» → войти в Instagram → скопировать маркер.
2. Открыть http://localhost:3000/settings, вставить маркер, сохранить.
3. Маркер живёт 60 дней. Продлить можно кнопкой «Продлить маркер на 60 дней» на той же странице. Посоветуй пользователю поставить напоминание.

## Шаг 8. Проверить
1. http://localhost:3000/posts → загрузить посты. Должны появиться все публикации.
2. Открыть любой Reels → «Статистика». Если ошибка прав: вернуться к шагу 4.5 и после добавления разрешения сгенерировать маркер заново.
3. «Загрузить все комментарии». Если комментариев 0 при ненулевом счётчике: приложение ещё не в Live (шаг 5).
4. Транскрипт видео: работает, если задан ключ OpenAI.

## Частые ошибки
- «Error validating access token: The session has been invalidated…»: пароль Instagram или Facebook менялся, нужен новый маркер (шаг 7).
- «Чтобы использовать конфигурацию Instagram API с единым входом, нужно выбрать бизнес-портфолио»: открыт не тот пункт, нужен «Настройка API для входа в Instagram для бизнеса».
- Статистика отдаёт ошибку прав: не добавлено `instagram_business_manage_insights` или маркер сгенерирован до добавления.
- Порт 3000 занят: запустить `npm run dev -- -p 3001` и открыть http://localhost:3001.

## Что дальше
Когда всё работает, пользователь может выгрузить полный файл аккаунта (кнопка «Бриф для агента» на /drafts или `/api/export?kind=brief`) и проанализировать свои рилсы промптом из `PROMPT_7_GREHOV.md`.
